# Валерия Павлухина — твой визажист

Одностраничное портфолио на HTML, CSS и JavaScript. Без сборки и установки зависимостей. Все фотографии и шрифты хранятся локально; сайт работает с GitHub Pages и подкаталогами репозитория.

## Локальный просмотр

Нужен Node.js. В папке проекта:

```sh
npm run dev
```

Открыть http://127.0.0.1:4173. Проверка файлов и содержимого: `npm run check`.

## Публикация через GitHub Pages

1. Создать репозиторий в своём GitHub и загрузить туда файлы проекта, сохранив структуру папок.
2. Открыть Settings → Pages → Build and deployment.
3. Выбрать Deploy from a branch, свою основную ветку и папку `/ (root)`, сохранить.
4. Дождаться публикации; GitHub покажет адрес сайта в разделе Pages.

Удалённый репозиторий пока не подключён. Сайт не опубликован.

## Обновление

- Тексты, цены, адрес и ссылки: `index.html`.
- Цвета и оформление: `styles.css` (переменные в `:root`).
- Фото и оригиналы отзывов: `assets/images/`.
- Поведение меню и увеличения изображений: `script.js`.
- Факты и согласованные требования: `PRODUCT.md`.

При замене контактного номера обновить `tel:`, WhatsApp и видимый текст. Telegram-ссылки также есть в `script.js`. При изменении цены проверить все упоминания и `tools/check.cjs`.

Фотографии и отзывы предоставлены пользователем. Шрифты Cormorant Garamond, Manrope, Bad Script распространяются по SIL Open Font License, лицензии лежат в `assets/fonts/`. Подробности источников — `ASSETS.md`.
